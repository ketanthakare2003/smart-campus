# Smart Campus Management System

The Smart Campus Management System is a full-stack, enterprise-grade application designed to streamline campus recruitments, academic notices, placement drives, company evaluations, and administrative audits.

## 🚀 Features

- **Multi-Role Dashboards**: Customized user interfaces for **Admin**, **Students**, **Faculty**, **Training & Placement Officers (TPOs)**, and **Recruitment Companies**.
- **Secure JWT Authentication**: Role-based access control (RBAC) with stateless token sessions.
- **Enterprise Onboarding & Verification Workflow**:
  - **Students**: Registered accounts initialize with `PENDING_VERIFICATION`. Student can edit their profile but cannot view job listings, apply, or check placement drives until a Faculty or TPO approves their profile.
  - **Faculty, TPOs, & Companies**: Registration requires entering a valid, single-use, unexpired **Registration Code** generated by the Admin. Valid accounts are created in `PENDING_ADMIN_APPROVAL` state, and users see a pending approval notice screen until the Admin activates their account.
  - **Admins**: Public registration for Admin accounts is blocked.
- **Verification Code Manager**: Admin control panel to generate unique single-use registration codes (assigning target role, expiration duration, and tracking used status).
- **Approvals Dashboards**:
  - Faculty & TPOs can review and approve student profiles.
  - Admins can verify and approve Faculty, TPO, and Company accounts.
- **Placement Drive Planner**: TPOs organize schedules, eligible departments, and CGPA cutoffs.
- **Notice Board**: Public announcements board managed by Faculty and Admins.

## ⚙️ Setup and Configuration

### Prerequisites
1. **Java Development Kit (JDK) 17**
2. **Node.js** (v18 or higher) & **npm**
3. **PostgreSQL** Database

### 1. PostgreSQL Database Configuration
Create a database named `smart_campus` in your PostgreSQL instance:
```sql
CREATE DATABASE smart_campus;
```

Update [application.properties](file:///c:/Users/91749/smart-campus-ai/backend/src/main/resources/application.properties) with your database username and password:
```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/smart_campus
spring.datasource.username=postgres
spring.datasource.password=YOUR_PASSWORD
```

### 2. Backend Setup
1. Open the `backend` folder in IntelliJ IDEA or Eclipse.
2. Let the IDE import the Maven project and download dependencies.
3. Locate `SmartCampusApplication.java` and click **Run**.
4. Access the interactive Swagger OpenAPI Documentation:
   - **Swagger UI**: `http://localhost:8080/swagger-ui.html`

### 3. Frontend Setup
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Launch local dev server:
   ```bash
   npm run dev
   ```
4. Access web app in browser: `http://localhost:5173`

## 🛡️ Onboarding Verification Flow (Testing Guide)

1. **Accessing Admin**: Since public registration for Admin is disabled, you can insert a default Admin user directly into your PostgreSQL database using SQL to kickstart operations:
   ```sql
   INSERT INTO users (full_name, email, password, role, status)
   VALUES ('Campus Administrator', 'admin@campus.edu', '$2a$10$Y5n2v0QzO7qKkQ72XmU6ueuB8Z2h4uWb.J.O96.b68.L68g0g9b8a', 'ADMIN', 'ACTIVE');
   ```
   *(Note: The password above hashes to `admin123` via BCrypt)*.
2. **Generate Code**: Log in as Admin. Navigate to **Registration Codes** in the sidebar. Select a role (e.g. `Faculty`) and click **Generate Key**.
3. **Sign Up Faculty/Company**: Navigate to `/register` and choose the corresponding role. Paste the generated key and complete registration.
4. **Approve Profile**: Log in as Admin. Navigate to **Approve Profiles**. Approve the newly registered Faculty/Company account.
5. **Verify Student**: Register a new Student account (no key required). Log in as Student; you'll see a warning banner and placement features are locked. Log in as Faculty or TPO, go to **Verify Students**, and click **Verify**. The Student account is now active and unlocked!
